# References — SOLO CONCEPTUAL

> **Nada de esta carpeta es un sprite del juego.** Son láminas de referencia (1536 × 1024) y una foto, no celdas transparentes de 128 × 128 listas para cargar. El proyecto no las copia al mod (`DoctorSimiBoss.csproj` solo empaqueta `Sprites/` y `Effects/`), `animation_manifest.json` las declara en `conceptReferences` y `ManifestValidator` da error si alguna aparece como cuadro de animación.

Contiene la foto aportada por el usuario y las láminas conceptuales de Spawn, Idle, Walk, Attack, Hurt, Stun, Defeat y PunchImpact.

- special_attacks_concept_sheet.png: seis poses de ataque para diseñar el combate por fases; lámina de referencia, no sprites finales.


- saludo_cargado_concept_sheet.png: seis poses de referencia del ataque Saludo cargado (guardia, anticipación, extensión, recuperación y retorno); fondo oscuro, no usar como sprite final.
